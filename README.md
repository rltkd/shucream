# 🍰 나만의 슈 찾기 프로젝트

그림책 감상 활동과 연계하여 제작한 참여형 웹사이트입니다.  
사용자는 선택받지 못한 작은 슈크림이 되어, 새로운 길을 찾아가는 과정에서 9개의 질문에 답하게 됩니다.

선택 결과에 따라 총 8가지 슈 유형 중 하나가 제시되며, 참여자들의 결과 분포도 함께 확인할 수 있습니다.

## 🔗 체험하기

[나만의 슈 찾기 프로젝트 바로가기](https://rltkd.github.io/shucream/)

QR코드를 통해 모바일에서도 간편하게 참여할 수 있습니다.

## 📖 활동 개요

빵집 진열대에 홀로 남겨진 작은 슈크림.  
선택받지 못한 채 밖으로 나온 슈크림은 자신만의 길을 찾아 떠납니다.

참여자는 이야기 속 상황에서 선택을 이어가며, 마지막에 자신에게 해당하는 슈의 모습을 확인하게 됩니다.

## 🎮 진행 방식

1. `여정 시작하기` 버튼을 눌러 활동을 시작합니다.
2. 총 9개의 상황형 질문에 답합니다.
3. 선택 결과를 바탕으로 성향이 계산됩니다.
4. 최종적으로 8가지 슈 유형 중 하나가 표시됩니다.
5. 결과 화면에서 참여자들의 전체 슈 분포를 확인할 수 있습니다.

## 🧁 결과 유형

| 유형 | 별명 |
|---|---|
| 🍓 딸기슈 | 따뜻한 공감가 |
| 🍦 바닐라슈 | 든든한 관리자 |
| 🍋 레몬슈 | 모험을 사랑하는 탐험가 |
| 🔥 시나몬슈 | 열정적인 리더 |
| 🌙 달빛슈 | 감성 이야기꾼 |
| 🍫 초코슈 | 성실한 장인 |
| 🌈 무지개슈 | 자유로운 창작자 |
| ☕ 에스프레소슈 | 독립적인 개척자 |

## 🧭 성향 기준

결과는 다음 세 가지 성향 축을 바탕으로 결정됩니다.

| 성향 축 | 설명 |
|---|---|
| 친구형(F) ↔ 독립형(I) | 사람들과 함께 해결하는가, 혼자만의 방식으로 해결하는가 |
| 안정형(S) ↔ 도전형(C) | 익숙한 환경을 선호하는가, 새로운 가능성에 끌리는가 |
| 감성형(E) ↔ 현실형(R) | 마음과 감정을 중시하는가, 판단과 적합성을 중시하는가 |

## 📊 통계 기능

결과 화면에서는 참여자들의 슈 유형 분포를 확인할 수 있습니다.

- 같은 활동 회차에서는 한 기기의 첫 번째 결과만 통계에 반영됩니다.
- 다시 체험하더라도 개인 결과는 확인할 수 있습니다.
- 이전 기록을 삭제하지 않고, 활동 회차별로 새로운 통계를 시작할 수 있도록 구성하였습니다.

## 🎓 제작 목적

본 프로젝트는 그림책 감상 활동을 단순 발표에서 끝내지 않고, 참여자가 이야기 속 선택을 직접 경험하도록 구성한 웹 기반 활동입니다.  
자신의 결과를 확인하고 다른 참여자들의 분포를 함께 살펴보며, 각자의 선택과 개성을 자연스럽게 이야기할 수 있도록 제작하였습니다.
